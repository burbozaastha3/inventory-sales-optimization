# Inventory, Purchase & Sales Analysis
## Data
- Original raw datasets are available [here](https://www.kaggle.com/datasets/sloozecareers/slooze-challenge/data). 
- Processed datasets used in analysis are included in `data/processed/`.

## Requirements

This project is implemented in Python and requires the following libraries:

- pandas  
- numpy  
- matplotlib  
- seaborn  
- jupyter  

---

## Installation

Install the required libraries using pip:

```bash
pip install pandas numpy matplotlib seaborn jupyter

## How to Run

1. Clone the repo:
   git clone https://github.com/burbozaastha3/inventory-sales-optimization
2. Download raw datasets from [Kaggle Link] and place them in `data/raw/`.
3. Install required packages:
   pip install -r requirements.txt
4. Run the notebooks in order:
   - `notebooks/_analysis_.ipynb`
